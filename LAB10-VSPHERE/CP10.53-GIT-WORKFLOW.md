# CP10.53 - Git Branch Workflow

## Environment
- Infrastructure: VMware vSphere
- IaC Tool: Terraform
- Environments: DEV / TEST / PROD
- State: Isolated per environment

## Git Workflow
1. Create feature branch
2. Make changes
3. Review changes
4. Commit
5. Merge into main

## Safety Rules
- Never commit Terraform State
- Never commit credentials
- Review terraform plan before apply
- Protect production resources
